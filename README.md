 # Flights-powerbi-daashboards
This repository contains an interactive Power BI Dashboard designed to analyze key metrics related to flight operations, delays, aircraft types, origins–destinations, and airline performance.
The project showcases data visualization, DAX calculations, and insights generation using multiple report pages.

My project
🛠️ Tools & Technologies Used

* Power BI Desktop

* DAX Measures

* Data Modeling

* Interactive Slicers & Filters

* Charts: Bar, Pie, Scatter, Line, KPI Tiles

🔍 Project Overview

The purpose of this dashboard is to provide a clear, data-driven view of:

* Flight volume trends

* Airline performance

* Aircraft type distribution

* Route analytics

* Delay patterns by airline, time, and date

* Status distribution (On-Time, Delayed, Cancelled)

Each report page focuses on a specific operational aspect of the dataset.


📄 Page 1 – Flight Overview Dashboard

This page provides a complete summary of total flights and distribution across airlines, aircraft types, and dates.

Visuals Included

* Total Flight Count (KPI Tile)
Shows total number of flights recorded in the dataset.

* Count of FlightID by Airline (Bar Chart)
Helps compare airline performance by total flights operated.

* Aircraft Type Distribution (Pie Chart)
Displays the share of each aircraft model (A320, A380, B737, B777, B787).

* Flight Volume Across Timeline (Line Chart)
Shows daily fluctuations in flight counts for trend monitoring.



📄 Page 2 – Delay Analysis Dashboard

This page highlights overall delay behavior and airline-specific performance.

Visuals Included

* Average Delay Time (KPI Tile)
Shows the overall mean delay in minutes.

* Average Delay by Airline (Bar Chart)
Compares airline performance in terms of punctuality.

* Sum of Delay Minutes by Arrival Time (Scatter Plot)
Helps identify time-of-day patterns for higher delays.

* Delay Trend by Date (Line Chart)
Highlights variations in delay over the entire dataset timeline.

* Status Slicer
Filters data into: On-Time, Delayed, Cancelled.


📄 Page 3 – Origin & Destination Dashboard

A detailed page dedicated to route and traffic analysis.

Visuals Included

* Unique Destination Count (KPI Tile)
Total number of unique destination airports.

* Filter by Origin (Slicer)
Allows selecting specific origins like BLR, BOM, DEL, DXB, etc.

* Count of Flights by Destination (Bar Chart)
Identifies busiest arrival airports.

* Origin Distribution (Pie Chart)
Displays flight share by origin airports.

* Count of FlightID by Departure Time (Line Chart)
Reveals departure time patterns, peak periods, and traffic density.

📄 Page 4 – Airline & Aircraft Interaction Dashboard

A combined view showing how aircraft types and status categories perform within each airline.

Visuals Included

* Total Airline Count (KPI Tile)
Shows total number of airline entries/flight records.

* Date Range Slicer
Controls the entire dashboard based on selected dates.

*Flight Count by Airline & Aircraft Type (Stacked Bar Chart)
Shows which aircraft types each airline uses most.

* Flight Status Distribution (Pie Chart)
Breakdown of:

* On-Time

* Delayed

* Cancelled

*Daily Flight Count by Date (Line Chart)
Shows long-term flight frequency trends.
